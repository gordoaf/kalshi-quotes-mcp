# Changelog

## 0.1.0 — 2026-11-18

Initial beta release for desktop testing and self-hosting.

- Batch YES/NO quotes for up to 100 exact tickers, preserving decimal precision.
- Market discovery with filters and pagination, market rules, and order-book depth.
- Explicit missing liquidity, inactive markets, and source/retrieval metadata.
- Local stdio and Streamable HTTP, with bounded requests and host/origin protection.
- Git installation, Docker packaging, client guides, and offline protocol tests.

Client-specific end-to-end setup is still being exercised; see docs/clients.md.
